KimiKiss English Patch

Fan English translation of KimiKiss (キミキス, Enterbrain) for PlayStation 2.
Full script of about 35,000 lines, all routes, menus, name entry, save screens and in-game images.

Download the patch (.xdelta) Source on GitHub Discord

Status

Test release. The translation was produced with AI assistance and spot-checked, not yet read through by a human editor. The first days were played in PCSX2 without problems; later routes are not fully checked. Reports and fixes are welcome.

What you need

  • Your own dump of the disc: eb!Kore+ KimiKiss, serial SLPS-25850, 1,267,597,312 bytes, SHA-1 40a70c43ef4c57b8bcdfeab3814437c3eaf4821c. The patch does not work on other editions.
  • An xdelta patcher (xdeltaUI, Delta Patcher or xdelta3).
  • PCSX2.

How to patch

  1. Check the SHA-1 of your ISO (certutil -hashfile KimiKiss.iso SHA1 on Windows, sha1sum KimiKiss.iso elsewhere).
  2. Download KimiKiss_EN.xdelta.
  3. Apply it: source = your ISO, patch = KimiKiss_EN.xdelta, output = KimiKiss_EN.iso.
  4. Start KimiKiss_EN.iso in PCSX2.

Building the patch from source and changing the translation are described in the README and How to translate.
